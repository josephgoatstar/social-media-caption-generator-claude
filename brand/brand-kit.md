# OCAC Caption Brand Kit: "Whimsy Kit" v1

The goal: someone scrolling sees a post and knows it's OC Anime Club **before reading
the handle**, the same way @parfaitdayy is recognizable from ♡ bullets alone. That comes
from repeating the **same few signatures on every post**, not from more decoration.

**Theme:** *whimsy × cybersigil × side quest.* Soft and cute (🫧🖤, kaomoji) meets sharp
and mystical (⟡ ✦ glyphs, blackletter), wrapped in a friendship-as-an-RPG metaphor
(find your party, side quest, player 2).

Everything below is copy-paste ready.

---

## 1. The 5 signatures (use ALL of these on every IG/TikTok event post)

| # | Signature | Copy |
|---|---|---|
| 1 | **Title frame:** the event name between 🫧 | `🫧 EVENT NAME 🫧` |
| 2 | **Section headers:** ⟡ + lowercase label | `⟡ the vibe` · `⟡ the deets` · `⟡ the party` |
| 3 | **Feature bullets:** ✦ (already ours, keep it) | `✦ ` |
| 4 | **Details block:** fixed emoji keys, same order every time | see §3 |
| 5 | **Sign-off:** divider + mission line | `⊹ ⟡ keep socal whimsical ⟡ ⊹` |

Community/meme posts use at least #3 and #5.

## 2. Glyph palette

```
✦  primary bullet / genre separator
⟡  section headers, title accents
⊹  divider ends
ᯓ★ "quest" / adventure accent (use sparingly)
⋆  tiny sparkle filler
♱  dark/gothic events only (raves, Halloween, horror anime)
```
**Divider (one style, always the same):**
```
⊹ ⟡ ✦ ⟡ ⊹
```
**Genre/vibe line format:**
```
happy hardcore ✦ nightcore ✦ techno
```

## 3. Details block (identical structure every time)

```
⟡ the deets
🗓️ sat, oct 24 · 9 PM–1:30 AM
📍 Venue Name, City
🎟️ $15 early bird / RSVP → link in bio
🪪 18+   (or 21+ · ID + security at door)
```
Rules: day-of-week + date, en-dash time ranges, venue in Proper Case, age line ALWAYS.
Online events: `💻 discord vc · 7 PM PT`.

## 5. Fancy-font lines (ONE line per caption, decoration only)

Fancy Unicode isn't searchable and screen readers stumble on it. **Never** use it for the
event name, date, place, or keywords. Use it for a subtitle, a quote, or a closing line.

| Mood | Style | Example |
|---|---|---|
| Dark / rave / gothic | blackletter | `𝔡𝔞𝔯𝔨𝔫𝔢𝔰𝔰 𝔟𝔢𝔠𝔬𝔪𝔢𝔰 𝔩𝔦𝔤𝔥𝔱` |
| Cozy / social | italic serif | `𝒔𝒊𝒑 & 𝒔𝒐𝒄𝒊𝒂𝒍` |
| Gaming / cyber | monospace | `𝚙𝚕𝚊𝚢𝚎𝚛 𝟸 𝚑𝚊𝚜 𝚎𝚗𝚝𝚎𝚛𝚎𝚍` |

**Signature move (from our top post):** close with a fandom quote in a fancy font when
the event is themed to one anime or game. Fans recognize it and feel seen.

## 6. Brand vocabulary: friendship × RPG

Use **one** per caption so it stays charming, not cringe.

```
find your party          side quest unlocked       player 2
your friendship arc      the guild (= our discord) moots → real friends
main character energy    party's forming           respawn at the next one
```
**Signature phrases (rotate):**
```
keep socal whimsical
spreading whimsy one friend at a time
come solo, leave with a party
```

## 7. CTA bank (sends are our #1 signal)

**Send / share (default for event posts):**
```

send this to the friend you're dragging with you

send this to your cosplay bestie
```
**Discord sign-off (every public post, after the main CTA):**
```
🫧 the discord hears about events first → link in bio

```
**Easy comment prompts (when engagement is the goal):**
```

```
**Newcomer reassurance (use often, since it's our whole mission):**
```

```

## 9. Brand-kit checklist (run before posting)
- [ ] 🫧 title frame on the event name (plain text, not fancy font)
- [ ] ⟡ section headers + ✦ bullets
- [ ] details block in the fixed order, with the age line
- [ ] exactly one kaomoji
- [ ] one RPG/friendship phrase at most
- [ ] send CTA + Discord sign-off
- [ ] `⊹ ⟡ keep socal whimsical ⟡ ⊹` sign-off
- [ ] every collaborator credited with their exact @handle
- [ ] #ocanimeclub + 2–4 relevant tags

## 10. Making it visual (for flyer designers)
Share §1–§3 with flyer artists so the graphics match the captions:
- put a ⟡ or ✦ mark somewhere on every flyer (a corner stamp works)
- use the same detail order on the flyer: date · time · venue · price · age
- put a small "keep socal whimsical" tagline or the 🫧 mark on the footer
