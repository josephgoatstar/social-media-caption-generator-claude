# Hooks, Formulas, CTAs, Power Words

## Hook types (draft 3 different types per piece, keep the best)

| Type | Templates |
|---|---|
| **Provocation** | "Stop [doing X] — here's why" · "You're doing [X] wrong" · "[Common advice] is ruining your [result]" |
| **Curiosity gap** | "Nobody talks about [specific thing]" · "I tested [N] [things]. One wasn't even close." · "The [topic] mistake I made for [time]" |
| **Specific result** | "[Result] in [time] with [method]" · "How we got [number] [outcome] in [time]" |
| **Value / utility** | "Save this for when [situation]" · "[N] [things] I wish I knew before [X]" · "The [topic] cheat sheet" |
| **Relatable / POV** | "POV: [specific moment]" · "If you [specific behavior], this is for you" · "Me pretending I didn't [thing]" |
| **Emotion / honesty** | "Honest truth about [topic]" · "I almost didn't post this" · "One change flipped everything" |
| **Contrarian** | "Unpopular opinion: [claim]" · "[Popular thing] is overrated. Here's what works." |
| **Announcement** | "It's finally here." · "We've been hiding this for [time]" · "[Date]. Save it." |
| **Pattern interrupt** | "Don't watch this if [X]" · "Wait for it." · "This shouldn't work, but…" |

**Hook scoring (silent, 1–5 each):** stops the scroll · specific (number/name/result) ·
true to the content (no bait-and-switch) · sounds like the brand. Ship only ≥ 16/20.

## Formulas (no repeats across platforms in one response)

**Reach**
1. Trend + Benefit — "[Trend]: [benefit] for [audience]"
2. X vs Y — "[A] vs [B]: which actually [result]?"
3. Myth Buster — "Myth: [belief]. Reality: [truth]."
4. Data Teaser — "[Number] → [result] in [timeframe]"
5. What Works Now — "What's working in [niche] right now: [1], [2], [3]"
6. Watch-Time Promise — "[Time] to [result]. The last one's the best."
7. Beginner's Path — "New to [field]? [Step 1] → [Step 2] → [Step 3]"

**Engagement**
1. Micro-Decision — "[A] or [B]? Defend your answer."
2. Hot Take — "Unpopular opinion: [thesis]. Change my mind."
3. Rank These — "Rank them: [1], [2], [3]"
4. Fill the Blank — "Finish this: '[topic] is underrated because…'"
5. Story Prompt — "What's the worst [experience] you've had? I'll go first: [short story]"

**Sales / conversion**
1. PAS — "[Pain]? [Agitate in 1 line]. [Solution] → [result]."
2. Objection Flip — "Think '[objection]'? Here's the truth: [counter]."
3. Social Proof Lead — "'[Real quote]' — [name]. Here's what they did:"
4. Before/After/Bridge — "Before: [state]. After: [state]. The bridge: [product]."

**Growth**
1. Series — "Part [1/N]: [topic]. Follow so you don't miss [N+1]."
2. Keyword DM — "Comment '[WORD]' and I'll send you [resource]." (only if DM automation exists)
3. Cliffhanger — "[N] lessons from [experience]. First [k] here, rest tomorrow."

**Community / attendance (Discord, events, flyers)**
1. FOMO-Honest — "[Event] · [date]. Last time [real outcome]. Don't hear about it later."
2. Insider — "Members get [thing] first. [Time] until it's public."
3. Countdown — "[N] days. [What happens]. [Action] now."

## CTA menu (one per piece, matched to the signal)
| Signal | CTAs |
|---|---|
| Sends/shares | "Send this to the friend who [specific behavior]" · "Share with your [team/crew/roommate]" |
| Saves | "Save this for your next [situation]" · "Bookmark before you [action]" |
| Comments | A specific, easy-to-answer question · "1 or 2?" · "Wrong answers only:" |
| Follows | "Follow for part 2" · "Following = you'll catch the next [thing]" |
| Clicks | "Link in bio for [specific thing]" · "Full guide → link in bio" |
| Attendance | "RSVP in #events" · "React ✅ if you're coming" · "Tap Interested on the event" |

## Power words (2–3 per caption, never stacked)
| Category | Words |
|---|---|
| Urgency (only if true) | now, today, tonight, final, last call |
| Trust | tested, proven, real, actual, receipts |
| Exclusivity | insider, first look, members-only, behind the scenes, unreleased |
| Emotion | honest, wild, unexpected, raw, finally |
| Action | steal, try, unlock, grab, start |
| Value | cheat sheet, blueprint, template, breakdown, playbook |
