# Format Craft — Reels, Carousels, Flyers, Stories, Announcements

Platform files say *how long and where*. This file says *how to build each format so it works*.

---

## Reels / short video
The caption is the third hook, not the first. Deliver:
1. **On-screen hook** (≤ 7 words, frame 1): a tension, a number, or a promise.
   "3 bars locals won't tell you about" > "Best bars in the city".
2. **Spoken hook** (TikTok especially): first sentence includes the keyword.
3. **Caption:** extends the hook — the *why*, a tease for the payoff, then CTA.
Pattern options: Problem → payoff tease · Result first → "here's how" · Myth → truth ·
POV / relatable moment · Countdown list ("the last one is wild").

## Carousels (IG carousel / TikTok photo mode)
If the user gives a topic but no slides, outline them:
```
Slide 1 — HOOK headline (≤ 8 words) + optional sub-line
Slide 2 — Instant payoff or the problem stated sharply
Slides 3–N — one point per slide, ≤ 25 words each, numbered
Slide N-1 — the "aha" / best tip / proof
Slide N — CTA: "Save this" / "Send to someone who…" / "Follow for part 2"
```
Caption adds context + save CTA. Cover headline patterns: "[N] [things] that [result]" ·
"Stop [mistake]. Do this instead." · "The [topic] cheat sheet" · "[Before] → [After]".

## Flyers / static graphics
The flyer must pass the **3-second thumbnail test**: someone glancing at a tiny phone
preview knows *what* it is and *why care*.

**On-graphic copy hierarchy** (deliver this whenever a flyer is being designed or critiqued):
| Level | Content | Rule |
|---|---|---|
| Headline | The hook / event name | ≤ 6 words, biggest text |
| Subhead | The benefit or vibe | ≤ 10 words |
| Details | Date · Time · Place · Price | Exact; one line each; time zone if online |
| CTA | "RSVP at…", "Scan to join", "Link in bio" | One action |
| Small print | Age limits, sponsors, handle | Smallest text |

If the user sends a finished flyer, **audit it** briefly (missing details, too many words,
weak headline) before writing captions — 1–3 bullet fixes max.

**Caption for a flyer post:** hook (don't just repeat the headline) → why come / why care
→ details recap in one scannable block → CTA → hashtags (local tags for events).
Always include **alt text**.

**Event detail block** (reuse across platforms):
```
📅 Sat, Dec 5 · 9 PM
📍 [Venue], [City]
🎟️ [Price / Free w/ RSVP]
🔗 [Link in bio / RSVP link]
```

## Stories (IG / TikTok / FB)
Deliver a frame plan, not a caption:
```
Frame 1 — [text ≤ 12 words]   | Sticker: [poll/quiz/question/countdown/none] | Visual: [suggestion]
Frame 2 — …
Frame N — CTA frame: [text]   | Sticker: link "[sticker label]"
```
- 3–7 frames. Frame 1 hooks; the middle delivers; the end converts.
- At least one interactive sticker (polls/quizzes are the easiest win).
- Events/drops: countdown sticker on frame 1 or 2.
- Repurposing a reel/post into a story: "New post 👀" is weak — tease the payoff
  ("I almost didn't post this one") + share the post sticker.

## Discord announcements
See `discord.md`. Build principle: headline → why it matters → bolded details with
timestamps → ONE action → ping last.

## Multi-platform launch kit (when user says "launch", "event", or "drop" + `all`)
Produce a coordinated set: teaser (Discord + IG story) → main post (IG reel/carousel/flyer
+ TikTok) → Discord announcement → reminder (story countdown + Discord `@here`) →
recap. Keep core message identical; wording native to each platform.
